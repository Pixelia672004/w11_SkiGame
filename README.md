# w11 ASCIIスキーゲーム（学生配布版）

## 目的

完成済みのPythonゲームを実行し、**入力 → Stateの更新 → 描画**の仕組みを確認します。
第11回の必須演習では、滑走スコアの加算処理だけを実装します。

このプログラムは、**リアルタイムで動くCLIゲーム**です。Pygameは使用しません。

## 1. 準備・起動（Windows / VS Code）

1. `w11_SkiGame` などの**専用フォルダ**を作り、配布ファイルを展開します。過去の演習フォルダ全体をGit管理しないこと。
2. VS Codeで **「ファイル」→「フォルダーを開く」** を選び、この専用フォルダを開きます。
3. VS Codeの **「ターミナル」→「新しいターミナル」** を開きます。
4. 必要なライブラリを導入します（最初の1回）。

   ```cmd
   py -m pip install -r requirements.txt
   ```

5. ターミナルでゲームを実行します。

   ```cmd
   py w11_ski_demo.py
   ```

> `py` コマンドが使えない環境では `python` に読み替えてください。
> キー入力を扱うため、**「出力」ウィンドウではなく「ターミナル」から実行**してください。
> 表示が欠ける場合はターミナルを広げてください（目安：64列×21行以上）。

## 2. 操作方法

| キー | 動作 |
| --- | --- |
| Space | スタート／一時停止／再開 |
| ←／→ | 進行方向を左／右に切り替える |
| R | ゲームオーバー後にリスタート |
| Q | 終了 |

- `O` がプレイヤー、`A` が木、`*` が崖です。
- キー操作は**横に1マス移動する操作ではなく、進行方向の切り替え**です。
- **直進モードはありません**。開始時は右へ滑り、左キーで左、右キーで右へ切り替わります。
- 同じ方向のキーを何度押しても曲がり方は強くなりません。**コースが1行進むたびに左右どちらかへ1文字分移動します。** 左右を適切に切り替えることで、まっすぐに近いコースを維持できます。
- 進行距離100行ごとにゲーム内レベルが上がり、スクロールが少しずつ速くなります。
- `direction` は左が `-1`、右が `+1` です。`0`（直進）は使いません。
- 急旋回や慣性などの表現は、今後の発展改良の候補です。
- 一時停止中は経過時間・滑走距離・スコア・障害物の進行が止まります。

## 4. Gitで変更を記録する

今回の専用フォルダをVS Codeで開いた状態で、**ソース管理 → リポジトリを初期化**します。

1. **改修前**に配布ファイルをStageし、`Initial commit` でCommitします。
2. `update_distance_score()` を改修し、ゲームを実行して動作確認します。
3. Diffで変更を確認し、`Add distance scoring` でCommitします。
4. 次のコマンドで履歴を確認します。

   ```cmd
   git log --oneline
   ```

## 5. 提出用Git Bundleを作る

最終課題の提出方法を練習します。**Git管理しているフォルダ内**で実行してください。

```cmd
git status
git bundle create ../w11_学籍番号.bundle --all
```

- `学籍番号` は自分の番号に置き換えてください。
- `git status` で未Commitの変更が残っていないことを確認します。
- Bundleは **1つ上のフォルダ** に作成されます。
- BundleにはCommit済みの履歴が入ります。未Commitの変更は含まれません。
- 指定された提出フォームから `.bundle` ファイルを提出してください。

## よくある問題

- **`No module named curses`**：Windowsでは `py -m pip install windows-curses` を実行してください。
- **キー操作が効かない**：VS Codeのターミナル部分をクリックし、もう一度操作してください。
- **画面が小さい**：ターミナルの幅と高さを広げてください。
- **Commitできない**：`git config user.name` と `git config user.email` を確認してください。
- **Git管理の対象が違う**：`git rev-parse --show-toplevel` でリポジトリの場所を確認してください。
